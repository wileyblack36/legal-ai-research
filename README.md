# Legal AI Research

这是一个用于沉淀法律行业 AI、AI 前沿能力、Agent 应用、AI 合规与司法/监管案例研究的资料仓库。

## 仓库定位

本仓库不是单篇报告，而是一个长期研究资料库。核心目标是把零散检索、资讯跟踪、案例分析、模型评测和报告产物分层保存，方便后续复用、迭代和交叉引用。

重点关注方向：

1. AI 在法律行业的应用能力、真实边界与落地难点。
2. Agent、工具调用、RAG、知识库、合同审查、法律检索等法律科技场景。
3. AI 合规、监管、执法、司法案例及平台治理动态。
4. 主流模型在法律、推理、代码、检索和文档工作流中的表现差异。
5. 可复用的研究提示词、案例模板、报告框架和检索方法。

## 目录结构

```text
00_project/      项目说明、研究边界、长期问题清单
01_sources/      原始资料、链接摘录、法规/案例/文章来源记录
02_reports/      成稿报告、专题简报、阶段性研究结论
03_cases/        司法案例、执法案例、监管案例的结构化分析
04_notes/        临时笔记、模型使用感受、待整理材料
prompts/         可复用提示词、检索任务提示词、报告生成提示词
```

## 使用原则

- 先存来源，再写结论；重要判断尽量保留出处。
- 区分官方宣传、媒体报道、论文研究、用户实测和个人判断。
- 对 AI 产品能力保持核验意识，不直接采信营销口径。
- 法律案例按“事实—主张—依据—抗辩—程序阶段—结论/和解”拆解。
- 报告材料尽量保持可复制、可复用、可迁移。
