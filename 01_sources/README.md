# 01_sources

本目录用于保存原始资料和来源记录。

适合存放：

- 法规、监管文件、指南、草案原文链接
- 官方公告、执法文书、法院文件、诉状、和解协议
- 论文、研究报告、行业白皮书
- 媒体报道和二手解读
- 产品官网、发布会、模型文档、价格页
- MLex、法院 docket、监管机构网站等核验入口

建议记录字段：

```text
标题：
来源类型：官方 / 法院 / 监管 / 论文 / 媒体 / 公司宣传 / 其他
来源链接：
发布时间：
访问时间：
相关主题：
可信度备注：
可复用结论：
待核验问题：
```

使用原则：

- 官方宣传和第三方实测分开记录。
- 法律依据、案例文件优先保留原始出处。
- 涉及最新动态时，记录具体日期，避免后续混淆。
