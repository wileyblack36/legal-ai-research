# 03_cases

本目录用于保存 AI 相关司法、执法、监管案例的结构化分析。

重点案例类型：

- AI 虚假宣传 / AI washing
- 数据抓取、训练数据、版权纠纷
- 算法歧视、自动化决策、消费者保护
- 深度伪造、拟人化互动、未成年人保护
- AI 产品缺陷、误导性陈述、证券/消费者诉讼
- 监管机构行政执法、和解、承诺令

建议案例分析结构：

```text
一、摘要
二、案件基本信息表
三、原告/监管机构主张要点
四、法律依据及请求权基础
五、被告抗辩要点
六、证据链与争议焦点
七、程序状态
八、和解协议/裁判要点（如有）
九、可复用表述与边界
```

注意事项：

- 程序阶段必须写清楚，避免把起诉主张当成法院认定。
- 法条原文和中文翻译分开呈现。
- 被告抗辩、否认事实、未承认责任等表述要保留。
