# 02_reports

本目录用于保存正式或半正式研究输出。

适合存放：

- 法律行业 AI 应用报告
- AI 合规阶段性简报
- 模型能力对比报告
- Legal Agent 专题报告
- 监管/司法动态月报
- 面向法务汇报的短文稿

建议命名：

```text
YYYY-MM-DD_主题_版本.md
```

示例：

```text
2026-06-legal-ai-application-report-v1.md
2026-06-eu-ai-act-transparency-article-50-brief.md
2026-06-legal-agent-capability-watch.md
```

写作原则：

- 摘要先行。
- 结论和证据分层。
- 重要判断说明依据强弱。
- 保留适合复制到汇报材料中的版本。
